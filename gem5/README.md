# gem5 による復元確認と弁別校正

## 目的

gem5 の役割は実機との一致を示すことではない。**提案した測定手法が、既知の
構成を持つ予測器に対して妥当であることを確認する**ことである。

1. **手法の妥当性の確認**: 構成が既知の予測器に対し、実機と同じ分岐列・同じ
   解析手順を適用して、設定した構成と整合する結果が得られるかを照合する。
2. **弁別の校正**: 対象パラメータのみが異なる二構成で、同じ分岐列の信号が
   実際に変わることを確認する。変わらなければその分岐列はそのパラメータを
   分離できていないため、設計を改める。

## 想定する構成

- 予測器: TAGE 系、および上位機構を含む構成（ループ予測器あり／なし、SC あり／なし）
- 振るパラメータ: テーブル数、履歴長の範囲、各テーブルサイズ

## 注意

- stat 名・パラメータ名はバージョンで異なる。着手時に自分のインストール版の
  `stats.txt` と予測器の設定ファイルで名前を突き合わせること。
- gem5 は一つのモデルであり実機の実装そのものではない。ここで確認するのは
  手法が意図どおり機能することであって、実機の結論ではない。
